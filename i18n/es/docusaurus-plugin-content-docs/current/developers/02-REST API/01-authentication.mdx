# Autenticación REST

URL base de producción: `https://api.clocktower.finance`. Las rutas a continuación son relativas a ese host (sin prefijo `/api`). El `wrangler dev` local usa las mismas rutas con prefijo `/api` en `http://127.0.0.1:8787`.

La API REST admite tres modos de acceso. x402 **no** se usa en REST — solo en MCP.

| Método | Cuándo |
|--------|------|
| Ninguno | Nivel gratuito — llama directamente cualquier endpoint permitido |
| `Authorization: Bearer <session>` | Nivel Builder — después de verificar SIWE |
| x402 | **Solo MCP** — no se usa en REST |

## Nivel gratuito

No se requiere clave API. Envía solicitudes directamente a `/*`. Se aplican límites de tasa por IP.

## Nivel Builder (sesión SIWE)

El acceso Builder requiere una suscripción on-chain **ACTIVE** al derecho Builder del servidor (`BUILDER_SUB_ID`).

### Flujo

1. `POST /auth/challenge` con `{ "address": "0x…" }` → recibe `message` + `nonce`
2. `personal_sign` de la wallet en el mensaje
3. `POST /auth/verify` con `{ "message", "signature" }` → recibe `token`
4. Envía `Authorization: Bearer <token>` en llamadas posteriores a `/api`

### Alcance Builder

- Cuenta propia (`/accounts/me`, …)
- Suscripciones de contenido a las que te suscribes o que creaste
- Escrituras de descubrimiento y suscriptores para tu wallet

La gestión de proveedores y las lecturas entre cuentas **no** están incluidas en el alcance Builder. Usa el nivel gratuito para lecturas públicas entre cuentas.

### Token de sesión

El token de sesión (`cts_…`) no es una clave API precompartida. Se obtiene vía SIWE y se almacena en caché en el cliente.

Consulta el [flujo de autenticación Builder](/docs/developers/Workflows/builder-auth).

## Basic Auth opcional

HTTP Basic Auth en `/api` se controla mediante `API_REQUIRE_BASIC_AUTH` (predeterminado `false`). Destinado solo para desarrollo local.

## CORS

Las solicitudes cross-origin del navegador están deshabilitadas por defecto. Operaciones debe incluir orígenes en la lista blanca vía `API_CORS_ALLOWED_ORIGINS`. CORS no se concede por una suscripción Builder.
