# Inicio Rápido de la API REST

Esta es la forma más rápida de probar Clocktower desde cualquier stack que hable HTTP. Obtienes lecturas y escrituras preparadas sin un cliente MCP ni un SDK on-chain — solo `curl`, `fetch` o el cliente HTTP que ya uses.

La API REST expone las mismas capacidades que MCP sobre HTTP estándar. **No se requiere pago x402** — el acceso se controla mediante límites de tasa y sesiones Builder opcionales. Si es tu primera vez aquí, empieza con el catálogo y una búsqueda de suscripciones más abajo; tendrás datos reales del protocolo en menos de un minuto.

## URL base

```
https://api.clocktower.finance
```

## Leer el estado del protocolo

```bash
curl -s https://api.clocktower.finance/catalog | jq .
curl -s https://api.clocktower.finance/protocol/state | jq .
```

## Buscar suscripciones

```bash
curl -s "https://api.clocktower.finance/subscriptions?first=10" | jq .
```

## Preparar una suscripción (solo preparación)

Verifica si una cuenta puede suscribirse sin generar transacciones sin firmar:

```bash
curl -s -X POST https://api.clocktower.finance/prepare/subscribe \
  -H "Content-Type: application/json" \
  -d '{
    "from": "0xYourAddress",
    "subscription": { "id": "0x..." },
    "readinessOnly": true
  }' | jq .
```

## Preparación completa

Omite `readinessOnly` para recibir `unsignedTransactions`, simulación y estimaciones de gas:

```bash
curl -s -X POST https://api.clocktower.finance/prepare/subscribe \
  -H "Content-Type: application/json" \
  -d '{
    "from": "0xYourAddress",
    "subscription": { "id": "0x..." }
  }' | jq .
```

Firma `unsignedTransactions` en tu wallet, transmite a Base y luego consulta el estado:

```bash
curl -s -X POST https://api.clocktower.finance/transactions/status \
  -H "Content-Type: application/json" \
  -d '{ "hash": "0x..." }' | jq .
```

## Sesión Builder (opcional)

Para límites más altos y rutas `:me`:

```bash
# 1. Desafío
curl -s -X POST https://api.clocktower.finance/auth/challenge \
  -H "Content-Type: application/json" \
  -d '{ "address": "0xYourAddress" }'

# 2. Firma el mensaje devuelto con tu wallet (personal_sign)

# 3. Verificar
curl -s -X POST https://api.clocktower.finance/auth/verify \
  -H "Content-Type: application/json" \
  -d '{ "message": "...", "signature": "0x..." }'

# 4. Usa el token
curl -s https://api.clocktower.finance/accounts/me/subscriptions \
  -H "Authorization: Bearer cts_..."
```

Consulta [Autenticación](/docs/developers/REST%20API/authentication) y el [flujo de autenticación Builder](/docs/developers/Workflows/builder-auth).

## Ayudante CLI

El repositorio [clocktower-agent](https://github.com/clocktower-protocol/clocktower-agent) proporciona un CLI de Node:

```bash
npm start rest get /catalog
npm start rest get /protocol/state
npm start rest post /prepare/subscribe --body '{"from":"0x...","subscription":{...},"readinessOnly":true}'
```
