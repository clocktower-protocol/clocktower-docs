# Inicio Rápido MCP

Usa esta ruta cuando quien *llama* es un agente de IA, no tu propio backend. El servidor MCP expone herramientas del protocolo Clocktower para que un agente descubra suscripciones, inspeccione cuentas y solicite transacciones preparadas mediante una interfaz estándar de herramientas.

Conecta cualquier cliente compatible con MCP a `mcp.clocktower.finance`. El acceso usa los mismos límites free y **API keys de developer** opcionales (`ctk_…`) que REST — consulta [autenticación REST](/docs/developers/REST%20API/authentication) y [límites de tasa](/docs/developers/REST%20API/rate-limits). MCP es solo Base y no admite un argumento `chainId`.

## Endpoint

```
https://mcp.clocktower.finance
```

El cliente se conecta a la raíz del subdominio — sin sufijo `/mcp`.

## Requisitos

- Cliente compatible con MCP y transporte Streamable HTTP (o equivalente)
- API key de developer opcional (`ctk_…`) para más límites
- Wallet para firmar transacciones preparadas

## Añadir el servidor

Apunta tu cliente MCP al endpoint. Ejemplo de configuración usado por muchos clientes (nivel free):

```json
{
  "mcpServers": {
    "clocktower": {
      "url": "https://mcp.clocktower.finance"
    }
  }
}
```

Para usar una API key de developer, añade `"headers": { "Authorization": "Bearer ctk_…" }` en esa entrada. Luego lista las tools (el cliente mostrará nombres como `get_protocol_state` y `search_subscriptions`) y llámalas con los argumentos JSON de abajo.

## Ejemplo: leer estado del protocolo

**Tool:** `get_protocol_state`

```json
{}
```

**Tool:** `search_subscriptions`

```json
{ "first": 10 }
```

## Ejemplo: leer suscripción

**Tool:** `get_subscription`

```json
{ "id": "0x..." }
```

## Crear una suscripción

`amount` es un string de token legible (p. ej. `"10"`), no wei del protocolo.

`frequency` es `0` semanal, `1` mensual, `2` trimestral, `3` anual.

`details.url` y `details.description` pueden ser strings vacíos.

**Tool:** `prepare_create_subscription`

```json
{
  "from": "0xProviderAddress",
  "amount": "10",
  "token": "0x...",
  "details": { "url": "https://example.com/", "description": "Premium" },
  "frequency": 1,
  "dueDay": 15
}
```

## Suscribirse

**Tool:** `prepare_subscribe_by_id`

```json
{
  "from": "0xYourAddress",
  "id": "0x...",
  "readinessOnly": true
}
```

La preparación completa devuelve `unsignedTransactions`, `signingMode`, `instructions` y `requestId`. Firma y transmite desde tu wallet, luego:

**Tool:** `get_transaction_status`

```json
{ "txHash": "0x..." }
```

## Flujo de escritura

```
check_*_readiness (opcional) → prepare_* → firmar → transmitir → get_transaction_status
```

Consulta el [flujo de escritura MCP](/docs/developers/MCP/write-workflow) y el [flujo de suscripción](/docs/developers/Workflows/subscribe).
