# Mapa de Exportaciones

| Importación | Descripción |
|--------|-------------|
| `@clocktower-protocol/sdk` | `ClocktowerClient`, ayudantes (montos, calendario, proxy transport), errores |
| `@clocktower-protocol/sdk/types` | Exportaciones solo de tipos |
| `@clocktower-protocol/sdk/react` | Hooks de wagmi + React Query |
| `@clocktower-protocol/sdk/subgraph` | Historial y descubrimiento GraphQL |
| `@clocktower-protocol/sdk/caller` | Escaneo de remit, preparación, bucle de ejecución |

## Tipos clave

Importa desde `@clocktower-protocol/sdk` o `@clocktower-protocol/sdk/types`.

### Enums

- `Frequency` — `WEEKLY`, `MONTHLY`, `QUARTERLY`, `YEARLY`
- `Status` — `ACTIVE`, `CANCELLED`, `UNSUBSCRIBED`

### Tipos principales

| Tipo | Campos clave |
|------|------------|
| `Subscription` | `id`, `chainId`, `amount`, `amountRaw`, `tokenDecimals`, `provider`, `token`, `cancelled`, `frequency`, `dueDay` |
| `EnrichedAccount` | `chainId`, `accountAddress`, `subscribedTo`, `created` |
| `ProtocolState` | `callerFeePercent`, `systemFeePercent`, `maxRemits`, `nextUncheckedDate`, `currentDate`, `isRemitCaughtUp` |
| `CreateSubscriptionParams` | `amount`, `token`, `details`, `frequency`, `dueDay` |
| `WriteOptions` | `skipSimulation`, `skipReadiness` (solo `remit()`), `waitForReceipt`, `gas` |
| `WriteResult` | `hash` |
