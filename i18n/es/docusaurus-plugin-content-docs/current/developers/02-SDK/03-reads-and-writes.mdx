# Lecturas y Escrituras

## Métodos de lectura

| Método | Devuelve | Notas |
|--------|---------|-------|
| `getSubscription(id)` | `Subscription` | Incluye `chainId`. Lanza `SubscriptionNotFoundError` para id cero |
| `getAccountSubscriptions(bySubscriber, address)` | `AccountSubscription[]` | `bySubscriber: true` lista suscripciones que la cuenta paga |
| `getSubscribers(id)` | `Subscriber[]` | Saldos de comisiones formateados según decimales del token |
| `getApprovedToken(token)` | `ApprovedToken` | Lanza `TokenNotApprovedError` si no está aprobado |
| `listApprovedTokens()` | `ListApprovedTokensResult` | Tokens conocidos de la config de cadena + `minimum` / `paused` on-chain |
| `checkSubscribeReadiness({ subscriptionId, account })` | `SubscribeReadinessResult` | No lanza; `ready` = sin bloqueos duros; `needsApproval` = allowance por debajo del amount |
| `getFeeBalance(id, subscriber)` | `FeeBalance` | Saldo de comisión prepagado |
| `getAccount(address)` | `Account` | Vista on-chain parseada |
| `getEnrichedAccount(address)` | `EnrichedAccount` | Saldos de comisiones en lote + `created` |
| `getProtocolState()` | `ProtocolState` | Comisiones, `maxRemits`, fechas de remit |
| `getSubscriptionsDue(day?)` | Resumen de cola de vencimientos | `dueCount`, `nextUncheckedDate`, `currentDate`, `isRemitCaughtUp`; anulación opcional de día |
| `watchSubscription(id, onUpdate, options?)` | `() => void` | Método del cliente; llama la función devuelta para detener |
| `waitForSubscription(id, options?)` | `Subscription` | Método del cliente; consulta hasta que exista (post-creación) |

Las escrituras de subscribe toman un **id** de suscripción, no un objeto guardado en el cliente. Amount, token y provider se cargan on-chain.

## Métodos de escritura (requieren `walletClient`)

| Método | Devuelve | Notas |
|--------|---------|-------|
| `createSubscription(params, options?)` | `WriteResult` | Valida `dueDay`, metadatos, mínimo del token |
| `subscribeById(id, options?)` | `WriteResult` | Carga la sub on-chain; requiere allowance ≥ amount |
| `subscribeWithApprovalById(id, account, options?)` | `{ approveHash?, hash }` | Aprueba si hace falta y luego suscribe. `account` debe coincidir con la wallet |
| `subscribeWithApprovalAutoById(id, account, options?)` | `SubscribeWithApprovalResult` | Lote EIP-5792 si está soportado; si no, secuencial |
| `unsubscribe(id, options?)` | `WriteResult` | El suscriptor se da de baja |
| `unsubscribeByProviderById(id, subscriber, options?)` | `WriteResult` | El proveedor elimina a un suscriptor |
| `cancelSubscription(id, options?)` | `WriteResult` | Cancelación por proveedor |
| `editDetails(id, details, options?)` | `WriteResult` | Actualiza URL/descripción |
| `editProviderDetails(details, options?)` | `WriteResult` | Campos del perfil de proveedor |
| `remit(options?)` | `WriteResult` | Pago permissionless. **Preverifica la cola de vencimientos por defecto** (el mismo escaneo que `checkRemitReadiness`); lanza `RemitNotReadyError` cuando no hay nada vencido. `{ skipReadiness: true }` para un `remit()` crudo. Los bots hacen bucle con `@clocktower-protocol/sdk/caller` |

Todas las escrituras lanzan `WalletRequiredError` cuando no hay `walletClient` con `account` configurado.

## Rangos de día de vencimiento

| `Frequency` | `dueDay` válido |
|-------------|----------------|
| `WEEKLY` (0) | 1–7 |
| `MONTHLY` (1) | 1–28 |
| `QUARTERLY` (2) | 1–90 |
| `YEARLY` (3) | 1–365 |

Para firmas de funciones on-chain, consulta la [Referencia Técnica del Contrato](/docs/contracts/Subscribe/subscribe_tech_reference).
