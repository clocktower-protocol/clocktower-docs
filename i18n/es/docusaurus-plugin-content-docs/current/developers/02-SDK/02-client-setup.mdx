# Configuración del Cliente

## Cliente independiente (scripts, backends)

```typescript
import { createClocktowerClient } from '@clocktower-protocol/sdk'
import { baseSepolia } from 'viem/chains'
import { http } from 'viem'

const client = createClocktowerClient({
  chain: baseSepolia,
  transport: http(process.env.RPC_URL!),
  walletClient,           // opcional — requerido para escrituras
  contractAddress,        // opcional — predeterminado a la configuración de cadena
  writes: { waitForReceipt: true },
  rpc: {
    retries: 2,
    timeoutMs: 30_000,
  },
})
```

## Desde wagmi/viem (dentro de ClocktowerProvider)

```typescript
import { createClocktowerClientFromViem } from '@clocktower-protocol/sdk'

const client = createClocktowerClientFromViem({ publicClient, walletClient })
```

## Cadenas compatibles

| Cadena | ID | Contrato |
|-------|-----|----------|
| Base | 8453 | `0xFaF5fc2f77b21BC188f492b827D366B03a07c61f` |
| Base Sepolia | 84532 | `0x6A0791Cd884f2199dC8F372f6715f675D2950922` |

`createClocktowerClient` lanza `UnsupportedChainError` para otros chain IDs. La cadena de la wallet debe coincidir con el cliente (`WalletChainMismatchError`). El `account` pasado a los helpers de approve debe coincidir con la wallet conectada (`WalletAccountMismatchError`).

Las lecturas marcan `chainId` en los objetos `Subscription` para que no se reutilicen entre cadenas.

## Opciones de escritura

Pasa por llamada o establece valores predeterminados vía `ClocktowerClientConfig.writes`:

```typescript
const { hash, gas, receipt } = await client.createSubscription(params, {
  waitForReceipt: true,
  skipSimulation: false,
})
```

`WriteResult` incluye `hash`, `gas` opcional y `receipt` opcional.
