# Conexión MCP

El servidor MCP expone herramientas del protocolo Clocktower en `mcp.clocktower.finance`. El uso de MCP alojado se rige por los [Términos de uso](/terms).

## Endpoint

```
https://mcp.clocktower.finance
```

El cliente MCP se conecta a la raíz del subdominio — sin sufijo de ruta `/mcp`.

## Acceso

MCP usa los mismos lanes **free** (por IP) y **developer** (`ctk_…`) que REST. Cada llamada a herramienta cuenta contra esos [límites de tasa](/docs/developers/REST%20API/rate-limits). Emite una key en [developers.clocktower.finance](https://developers.clocktower.finance) cuando necesites más límites de lectura. Ver [autenticación REST](/docs/developers/REST%20API/authentication).

Las keys inválidas o revocadas fallan la petición (**401**). **No** caen al nivel free.

## Configuración del cliente

Conéctate usando cualquier cliente compatible con MCP. Tu cliente debe admitir:

1. Transporte MCP a `mcp.clocktower.finance` (Streamable HTTP; sin sufijo `/mcp`)
2. Firma con wallet para transacciones preparadas

Ejemplo de configuración (nivel free — sin key):

```json
{
  "mcpServers": {
    "clocktower": {
      "url": "https://mcp.clocktower.finance"
    }
  }
}
```

Con una API key de developer, envía la misma cabecera `Authorization` que REST:

```json
{
  "mcpServers": {
    "clocktower": {
      "url": "https://mcp.clocktower.finance",
      "headers": {
        "Authorization": "Bearer ctk_…"
      }
    }
  }
}
```

Luego llama tools por nombre con argumentos JSON. Consulta el [inicio rápido MCP](/docs/developers/Getting%20Started/quickstart-mcp).

## Categorías de herramientas

| Categoría | Ejemplos |
|----------|----------|
| Lectura | `list_chains`, `get_protocol_state`, `get_subscription`, `get_account` |
| Descubrimiento | `search_subscriptions`, `get_subscription_details` |
| Historial | `get_subscription_history`, `get_account_activity` |
| Escritura (preparación) | `prepare_subscribe`, `prepare_create_subscription`, `prepare_remit` |
| Estado | `get_transaction_status`, `check_subscribe_readiness` |

Consulta la [referencia de herramientas](/docs/developers/MCP/tools-reference) para la lista completa.

## Protocolo

- **Cadena:** `chainId` opcional en las tools de protocolo; si se omite, se usa Base (`8453`). Ver [Selección de cadena MCP](/docs/developers/MCP/mcp-chain-selection).
- **Auth:** las mismas credenciales free y developer que REST
- **Escrituras:** solo preparación — el servidor nunca retransmite transacciones firmadas

REST usa `?chainId=` en el query string. MCP usa un argumento de tool. SIWE<IfFeature name="builder"> / el entitlement Builder</IfFeature> y los pagos x402 permanecen en Base.
