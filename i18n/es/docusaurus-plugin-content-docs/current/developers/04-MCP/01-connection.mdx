# Conexión MCP

El servidor MCP expone herramientas del protocolo Clocktower en `mcp.clocktower.finance`. El uso de MCP alojado se rige por los [Términos de uso](/terms).

## Endpoint

```
https://mcp.clocktower.finance
```

El cliente MCP se conecta a la raíz del subdominio — sin sufijo de ruta `/mcp`.

## Configuración del cliente

Conéctate usando cualquier cliente compatible con MCP. Tu cliente debe admitir:

1. Transporte MCP a `mcp.clocktower.finance`
2. Pagos x402 en USDC en Base para llamadas a herramientas
3. Firma con wallet para transacciones preparadas

## Categorías de herramientas

| Categoría | Ejemplos |
|----------|----------|
| Lectura | `get_protocol_state`, `get_subscription`, `get_account` |
| Descubrimiento | `search_subscriptions`, `get_subscription_details` |
| Historial | `get_subscription_history`, `get_account_activity` |
| Escritura (preparación) | `prepare_subscribe`, `prepare_create_subscription`, `prepare_remit` |
| Estado | `get_transaction_status`, `check_subscribe_readiness` |

Consulta la [referencia de herramientas](/docs/developers/MCP/tools-reference) para la lista completa y precios.

## CLI auxiliar

El repositorio [clocktower-agent](https://github.com/clocktower-protocol/clocktower-agent) proporciona un CLI en Node:

```bash
cd clocktower-agent
npm start mcp list
npm start mcp call get_protocol_state
```

## Protocolo

- **Cadena:** Base mainnet (chainId 8453). MCP **no** admite `chainId`; las tools siempre corren en Base.
- **Pagos:** micropagos x402 en USDC por llamada a herramienta
- **Escrituras:** solo preparación — el servidor nunca retransmite transacciones firmadas

REST puede seleccionar una cadena de protocolo con `?chainId=`. Eso no aplica a MCP. Ver [Selección de cadena](/docs/developers/REST%20API/chain-selection).
