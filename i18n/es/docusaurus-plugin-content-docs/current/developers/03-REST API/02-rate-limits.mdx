# Límites de tasa

Rutas relativas a `https://api.clocktower.finance`.

Los límites son **por identidad** (no un único cupo compartido para todos los usuarios). REST y MCP comparten estas identidades: una API key de developer usada en ambas superficies cuenta contra los mismos buckets.

Números canónicos: `GET /catalog` → `access.rest.*.limits` (`writeRpm`, `writeDaily`, `dailyTotalRequests`, …). Las llamadas a tools MCP usan las mismas cifras free y developer.

## Buckets de tasa

- **Global RPM** — la mayoría de las peticiones
- **Expensive RPM** — GETs pesados de subgraph / discovery
- **Subgraph diario** — rutas expensive que pegan a The Graph
- **Write RPM** — `POST /prepare/*`, `POST /check_subscribe_readiness` y `POST /check_remit_readiness`
- **Write diario** — el mismo conjunto, por día UTC (protege el coste de simulación en Alchemy)
- **Total diario** — cada petición REST y cada llamada a tool MCP ese día para esa identidad

Una llamada prepare consume **write RPM**, **write diario** y **total diario**.

REST `POST /check_subscribe_readiness_by_id` **no** entra en el bucket write (solo RPM cheap/global — no simula on-chain). La tool MCP `check_subscribe_readiness_by_id` **sí** consume el bucket write/readiness.

Las tools MCP `prepare_*` y las otras tools de readiness (`check_subscribe_readiness`, `check_remit_readiness`) usan los mismos buckets write que las rutas REST equivalentes.

## Por qué prepare está tan limitado

El prepare completo hace **simulación on-chain y estimación de gas**. El servidor nunca retransmite la transacción, pero el dry-run sigue costando RPC compartido. Los niveles free y developer son para exploración y **lecturas**; el volumen de escrituras en producción debe usar el **SDK con tu propio RPC**.

## Notas del nivel free

- Lecturas cross-account y de provider permitidas bajo el bucket expensive
- Búsqueda: `first` ≤ 10; sin `includeDetails=true`
<IfFeature name="builder">
- Las rutas `:me` requieren Builder (403 en caso contrario)
</IfFeature>

## Notas del nivel developer

- Más límites de lectura y discovery que free
- Búsqueda: `first` ≤ 25; `includeDetails` permitido
<IfFeature name="builder">
- Sigue sin `:me` (las keys no van ligadas a wallet)
</IfFeature>
- Keys inválidas/revocadas → **401**, no fallback a free

## Al superar un límite

HTTP **429** con `code: RATE_LIMITED`, `lane`, `Retry-After` y un `upgradeHint`. La cabecera `X-Clocktower-Lane` indica el lane aplicado.

## Catálogo legible por máquina

`GET /catalog` devuelve el manifiesto de rutas y límites en vivo. Ver [Catálogo](/docs/developers/REST%20API/catalog).

## Protecciones en el edge

Los despliegues de producción también pueden usar reglas de Cloudflare (rate limiting, WAF, bots) encima de los buckets de aplicación.
