# Catálogo de la API

`GET /catalog` en `api.clocktower.finance` devuelve el manifiesto legible por máquina de rutas, niveles de acceso, límites y el registro de cadenas.

## Ejemplo de petición

```bash
curl -s https://api.clocktower.finance/catalog | jq .

# Con key de developer
curl -s https://api.clocktower.finance/catalog \
  -H "Authorization: Bearer <YOUR_API_KEY>" | jq .
```

## Forma de la respuesta (v3)

```json
{
  "version": "3",
  "chainId": 8453,
  "chains": [
    {
      "chainId": 8453,
      "caip2": "eip155:8453",
      "name": "base",
      "rest": true,
      "mcp": true,
      "default": true
    }
  ],
  "pathNote": "On api host, omit the /api prefix (e.g. GET /catalog). Legacy workers.dev URLs keep /api. Protocol routes accept optional ?chainId= (decimal or CAIP-2 eip155:<id>); omitted uses DEFAULT_REST_CHAIN_ID.",
  "access": {
    "rest": {
      "free": {
        "auth": "none",
        "limits": {
          "globalRpm": 20,
          "expensiveRpm": 3,
          "subgraphDaily": 100,
          "writeRpm": 2,
          "writeDaily": 20,
          "dailyTotalRequests": 500
        }
      },
      "developer": {
        "auth": "API key (Authorization: Bearer ctk_…)",
        "enabled": true,
        "limits": {
          "globalRpm": 80,
          "expensiveRpm": 40,
          "subgraphDaily": 3000,
          "writeRpm": 5,
          "writeDaily": 100,
          "dailyTotalRequests": 5000
        },
        "management": {
          "create": "https://api.clocktower.finance/developer/keys",
          "list": "https://api.clocktower.finance/developer/keys?subjectId=",
          "revoke": "https://api.clocktower.finance/developer/keys/:id",
          "adminAuth": "Bearer <DEVELOPER_KEYS_ADMIN_SECRET> or X-Clocktower-Admin-Key"
        }
      }
    },
    "mcp": {
      "auth": "x402 (USDC on Base)",
      "limits": { "...": "..." }
    }
  },
  "apiEnabled": true,
  "developerKeysEnabled": true,
  "routes": [
    { "method": "GET", "path": "/api/catalog", "description": "..." }
  ]
}
```

- El `chainId` de nivel superior es el default REST cuando se omite `?chainId=`.
- `chains[]` lista las cadenas registradas (`rest`, `mcp`, `default`). Léelo en runtime en lugar de hardcodear IDs.
- El catálogo no se filtra por cadena, pero un `?chainId=` no soportado en la petición igual devuelve 400.

Usa el catálogo para descubrir endpoints y comprobar qué modos de auth y límites aplican en runtime. Los campos de límite incluyen `writeRpm`, `writeDaily` y `dailyTotalRequests`.

<IfFeature name="builder">
Cuando el entitlement Builder está configurado, el catálogo también incluye `builderAuthEnabled` y `access.rest.builder` (sesión SIWE, `cts_…`, endpoints `/auth/challenge` y `/auth/verify`).
</IfFeature>

Ver [Selección de cadena](/docs/developers/REST%20API/chain-selection).
