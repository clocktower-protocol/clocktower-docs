# Formato de Errores

Todos los errores devuelven una estructura JSON consistente:

```json
{
  "error": "Human readable message",
  "code": "VALIDATION_ERROR",
  "requestId": "optional-uuid-for-prepare-failures"
}
```

Un `?chainId=` REST no soportado (por ejemplo `1` o `not-a-chain`) devuelve **400** con `code: "VALIDATION_ERROR"` y un mensaje como `Unsupported chainId 1`. Ver [Selección de cadena](/docs/developers/REST%20API/chain-selection).

## Errores de validación

Los endpoints de escritura pueden incluir un array `issues` con detalles a nivel de campo:

```json
{
  "error": "Validation failed",
  "code": "VALIDATION_ERROR",
  "issues": [
    { "path": "from", "message": "Invalid address" }
  ]
}
```

## Fallos de preparación

Incluye `requestId` al reportar problemas de preparación.

Los fallos de prepare y simulación en REST devuelven `code: "VALIDATION_ERROR"`. Los fallos de la capa de preparación MCP devuelven `code: "PREPARE_FAILURE"`.

Los fallos de simulación en MCP lanzan excepción antes de devolver el resultado de la tool.
