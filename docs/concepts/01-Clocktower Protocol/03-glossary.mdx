# Glossary

## ERC-20

ERC20 tokens are fungible tokens on Ethereum. [More Detail](https://ethereum.org/en/developers/docs/standards/tokens/erc-20/). Each contract supports a tokens from an approved list. 

## Immutability

A synonym for unchangeable. Usually in regard to data on a blockchain which cannot be update or deleted once written.   

## Subscriber

In the context of subscriptions a subscriber is the person paying the regular transaction. 

## Provider

In the context of subscriptions the provider is user receinging the regular transaction. 

## Caller

The Caller is the name given to user to calls the contract at its regular timely interval. 

## REST API

HTTP interface to Clocktower protocol data and write preparation. Free tier with rate limits; optional Builder session for higher limits. See [Developers](/docs/developers/).

## MCP (Model Context Protocol)

Agent-facing tool interface at `mcp.clocktower.finance`. Paid per call via x402 USDC micropayments on Base. See [MCP Connection](/docs/developers/MCP/connection).

<IfFeature name="sdk">
## SDK

`@clocktower-protocol/sdk` — TypeScript client library for direct on-chain access via viem. See [SDK Installation](/docs/developers/SDK/installation).
</IfFeature>

## x402

Micropayment protocol used by the MCP server. Agents pay USDC on Base per tool call. See [x402 Payments](/docs/developers/MCP/x402-payments).

## Builder lane

REST access tier requiring SIWE wallet authentication and an on-chain Builder entitlement subscription. See [Builder Auth](/docs/developers/Workflows/builder-auth).
