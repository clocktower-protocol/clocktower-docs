# MCP Quickstart

Use this path when the *caller* is an AI agent, not your own backend. The MCP server exposes Clocktower protocol tools so an agent can discover subscriptions, inspect accounts, and request prepared transactions through a standard tool interface.

Connect any MCP-compatible client to `mcp.clocktower.finance`. Every tool call is paid via x402 in USDC on Base — see [x402 payments](/docs/developers/MCP/x402-payments) before you run your first call. MCP is Base-only and does not take a `chainId` argument.

## Endpoint

```
https://mcp.clocktower.finance
```

## Requirements

- MCP-compatible client
- x402 support for USDC payments on Base (all tool calls are paid)
- Wallet for signing prepared transactions

See [x402 payments](/docs/developers/MCP/x402-payments) for pricing and payment flow.

## List and call tools

Using [clocktower-agent](https://github.com/clocktower-protocol/clocktower-agent):

```bash
cd clocktower-agent
npm start mcp list
npm start mcp call get_protocol_state
npm start mcp call search_subscriptions '{"first":10}'
```

## Example: read subscription

```bash
npm start mcp call get_subscription '{"id":"0x..."}'
```

## Create a subscription

`amount` is a human-readable token string (e.g. `"10"`). `frequency` is `0` weekly, `1` monthly, `2` quarterly, `3` yearly.

```bash
npm start mcp call prepare_create_subscription '{
  "from": "0xProviderAddress",
  "amount": "10",
  "token": "0x...",
  "details": { "url": "https://example.com/", "description": "Premium" },
  "frequency": 1,
  "dueDay": 15
}'
```

## Subscribe

```bash
npm start mcp call prepare_subscribe_by_id '{
  "from": "0xYourAddress",
  "id": "0x...",
  "readinessOnly": true
}'
```

Full prepare returns `unsignedTransactions`, `signingMode`, `instructions`, and `requestId`. Sign and broadcast from your wallet, then:

```bash
npm start mcp call get_transaction_status '{"txHash":"0x..."}'
```

## Write workflow

```
check_*_readiness (optional) → prepare_* → sign → broadcast → get_transaction_status
```

See [MCP write workflow](/docs/developers/MCP/write-workflow) and [Subscribe workflow](/docs/developers/Workflows/subscribe).
