# SDK Installation

:::warning Pre-release
`@clocktower-protocol/sdk` is not published to npm yet. APIs may change before a stable release.
:::

## Install

```bash
npm install @clocktower-protocol/sdk viem
```

## Peer dependencies

For React hooks:

```bash
npm install react wagmi @tanstack/react-query
```

- **wagmi** ^3.0.0 — install connector packages separately (e.g. `@walletconnect/ethereum-provider` for WalletConnect)

## Build from source

```bash
git clone git@github.com:clocktower-protocol/sdk.git
cd sdk
npm install
npm run build
```
