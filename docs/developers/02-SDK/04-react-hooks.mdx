# React Hooks

Import from `@clocktower-protocol/sdk/react`. Requires `ClocktowerProvider` wrapping your app.

## Setup

```tsx
import { WagmiProvider } from 'wagmi'
import { QueryClient, QueryClientProvider } from '@tanstack/react-query'
import { ClocktowerProvider, useSubscription } from '@clocktower-protocol/sdk/react'

const queryClient = new QueryClient()

function App() {
  return (
    <WagmiProvider config={wagmiConfig}>
      <QueryClientProvider client={queryClient}>
        <ClocktowerProvider>
          <SubscriptionPage />
        </ClocktowerProvider>
      </QueryClientProvider>
    </WagmiProvider>
  )
}
```

## Query hooks

| Hook | Description |
|------|-------------|
| `useSubscription` | Single subscription by ID |
| `useProtocolState` | Protocol fee configuration and remit status |
| `useAccountSubscriptions` | Subscriptions for an account |
| `useEnrichedAccount` | Enriched account view |
| `useApprovedToken` | Token configuration |
| `useSubscriptionsDue` | Due-queue summary |

## Mutation hooks

Mutations take ids, not subscription objects.

| Hook | `mutate` argument |
|------|-------------------|
| `useCreateSubscription` | `CreateSubscriptionParams` |
| `useSubscribe` | `id` (`0x…`) |
| `useSubscribeWithApproval` | `{ id, account }` |
| `useSubscribeWithApprovalAuto` | `{ id, account, writeOptions? }` |
| `useUnsubscribe` | `id` |
| `useCancelSubscription` | `id` |
| `useEditDetails` | `{ id, details }` |
| `useEditProviderDetails` | `ProviderDetails` |

```tsx
import { useSubscribeWithApproval } from '@clocktower-protocol/sdk/react'

const subscribe = useSubscribeWithApproval()
subscribe.mutate({ id: subscriptionId, account })
```

Query keys are scoped by `chainId`. Mutations invalidate related queries on success.
