# Reads and Writes

## Read methods

| Method | Returns | Notes |
|--------|---------|-------|
| `getSubscription(id)` | `Subscription` | Includes `chainId`. Throws `SubscriptionNotFoundError` for zero id |
| `getAccountSubscriptions(bySubscriber, address)` | `AccountSubscription[]` | `bySubscriber: true` lists subscriptions the account pays for |
| `getSubscribers(id)` | `Subscriber[]` | Fee balances formatted per token decimals |
| `getApprovedToken(token)` | `ApprovedToken` | Throws `TokenNotApprovedError` if not approved |
| `listApprovedTokens()` | `ListApprovedTokensResult` | Known tokens from chain config + on-chain `minimum` / `paused` |
| `checkSubscribeReadiness({ subscriptionId, account })` | `SubscribeReadinessResult` | Non-throwing; `ready` = no hard blockers; `needsApproval` = allowance below amount |
| `getFeeBalance(id, subscriber)` | `FeeBalance` | Prepaid fee balance |
| `getAccount(address)` | `Account` | Parsed on-chain view |
| `getEnrichedAccount(address)` | `EnrichedAccount` | Batched fee balances + `created` |
| `getProtocolState()` | `ProtocolState` | Fees, `maxRemits`, remit dates |
| `getSubscriptionsDue(day?)` | Due-queue summary | `dueCount`, `nextUncheckedDate`, `currentDate`, `isRemitCaughtUp`; optional day override |
| `watchSubscription(id, onUpdate, options?)` | `() => void` | Client method; call returned function to stop |
| `waitForSubscription(id, options?)` | `Subscription` | Client method; poll until exists (post-create) |

Subscribe writes take a subscription **id**, not a client-held object. Amount, token, and provider are loaded on-chain.

## Write methods (require `walletClient`)

| Method | Returns | Notes |
|--------|---------|-------|
| `createSubscription(params, options?)` | `WriteResult` | Validates `dueDay`, metadata, token minimum |
| `subscribeById(id, options?)` | `WriteResult` | Loads on-chain sub; requires allowance ≥ amount |
| `subscribeWithApprovalById(id, account, options?)` | `{ approveHash?, hash }` | Approve if needed, then subscribe. `account` must match wallet |
| `subscribeWithApprovalAutoById(id, account, options?)` | `SubscribeWithApprovalResult` | EIP-5792 batch when supported, else sequential |
| `unsubscribe(id, options?)` | `WriteResult` | Subscriber unsubscribes |
| `unsubscribeByProviderById(id, subscriber, options?)` | `WriteResult` | Provider removes a subscriber |
| `cancelSubscription(id, options?)` | `WriteResult` | Provider cancels |
| `editDetails(id, details, options?)` | `WriteResult` | Updates URL/description |
| `editProviderDetails(details, options?)` | `WriteResult` | Provider profile fields |
| `remit(options?)` | `WriteResult` | Single permissionless payout; bots loop with `@clocktower-protocol/sdk/caller` |

All writes throw `WalletRequiredError` when no `walletClient` with `account` is configured.

## Due day ranges

| `Frequency` | Valid `dueDay` |
|-------------|----------------|
| `WEEKLY` (0) | 1–7 |
| `MONTHLY` (1) | 1–28 |
| `QUARTERLY` (2) | 1–90 |
| `YEARLY` (3) | 1–365 |

For on-chain function signatures, see [Contract Technical Reference](/docs/contracts/Subscribe/subscribe_tech_reference).
