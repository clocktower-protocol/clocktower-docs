# MCP Connection

The MCP server exposes Clocktower protocol tools at `mcp.clocktower.finance`. Hosted MCP usage is governed by the [Terms of Use](/terms).

## Endpoint

```
https://mcp.clocktower.finance
```

The MCP client connects to the subdomain root — no `/mcp` path suffix.

## Client setup

Connect using any MCP-compatible client. Your client must support:

1. MCP transport to `mcp.clocktower.finance` (Streamable HTTP; no `/mcp` path suffix)
2. x402 USDC payments on Base for tool calls
3. Wallet signing for prepared transactions

Example client config:

```json
{
  "mcpServers": {
    "clocktower": {
      "url": "https://mcp.clocktower.finance"
    }
  }
}
```

Then call tools by name with JSON arguments. See the [MCP quickstart](/docs/developers/Getting%20Started/quickstart-mcp).

## Tool categories

| Category | Examples |
|----------|----------|
| Read | `get_protocol_state`, `get_subscription`, `get_account` |
| Discovery | `search_subscriptions`, `get_subscription_details` |
| History | `get_subscription_history`, `get_account_activity` |
| Write (prepare) | `prepare_subscribe`, `prepare_create_subscription`, `prepare_remit` |
| Status | `get_transaction_status`, `check_subscribe_readiness` |

See [Tools reference](/docs/developers/MCP/tools-reference) for the full list and pricing.

## Protocol

- **Chain:** Base mainnet (chainId 8453). MCP does **not** accept `chainId`; tools always run on Base.
- **Payments:** x402 USDC micropayments per tool call
- **Writes:** prepare-only — server never relays signed transactions

REST can select a protocol chain with `?chainId=`. That does not apply to MCP. See [Chain selection](/docs/developers/REST%20API/chain-selection).
