# x402 Payments

All MCP tool calls require payment via the [x402 protocol](https://github.com/coinbase/x402) in USDC on Base.

## Requirements

- MCP client with x402 support
- USDC balance on Base for micropayments
- `PRIVATE_KEY` or wallet configured in your agent for payment signing

REST `/api` does **not** use x402. Use REST for free tier access with rate limits.

## Payment flow

1. Client calls an MCP tool
2. Server runs preflight/simulation (for prepare tools)
3. On success, x402 payment settles in USDC
4. Response is returned

Failed simulation or validation on prepare tools throws **before** payment settles.

## Pricing

Per-tool prices are listed in [Tools reference](/docs/developers/MCP/tools-reference). History and search tools use base price plus per-row surcharges.

## Cost estimation

Use clocktower-agent smoke tests to estimate MCP costs:

```bash
npm run smoke -- --list    # cost breakdown (REST free, MCP USDC)
npm run smoke -- --mcp-only --yes
```

## Recipient

The Worker receives payments at the address configured via `X402_RECIPIENT` environment variable.
