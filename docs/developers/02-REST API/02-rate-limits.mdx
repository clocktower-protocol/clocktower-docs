# Rate Limits

Paths are relative to `https://api.clocktower.finance`.

Access is tiered across free REST, Builder REST, and MCP lanes.

## Default limits

| Lane | Surface | Auth | Default limits |
|------|---------|------|----------------|
| **Free** | `api.clocktower.finance` | None | 20 rpm/IP; expensive routes 3 rpm; subgraph 100/day/IP; writes 2 prepare/min/IP |
| **Builder** | `api.clocktower.finance` | SIWE session | 120 rpm/address; subgraph 10k/day; writes 30/min; scoped to wallet |
| **Agent** | `mcp.clocktower.finance` | x402 | 300 rpm/IP; writes 60/min/address |

## Rate buckets

- **Global** — applies to most read endpoints
- **Expensive** — subgraph-heavy endpoints (history, discovery, cross-account reads)
- **Subgraph daily** — per-IP (free) or per-address (builder)
- **Write** — `prepare_*` endpoints, keyed on `from` address

## Free tier notes

- Cross-account and provider reads allowed under the expensive bucket
- Provider writes (`cancel`, `unsubscribe_by_provider`, `edit_details`) use the write bucket; on-chain authorization still applies in prepare handlers
- `:me` routes return 403 without a Builder session

## Machine-readable catalog

`GET /catalog` returns the full route manifest and tier limits. See [Catalog](/docs/developers/REST%20API/catalog).

## Edge protections

Production deployments should configure Cloudflare edge rules:

| Rule | Suggested config |
|------|------------------|
| Rate Limiting | Block `>500 req / 5 min` per IP on `api.clocktower.finance` and `mcp.clocktower.finance` |
| WAF | Block empty `User-Agent`; challenge `/auth/*` at `>30/min/IP` |
| DDoS | Keep HTTP DDoS managed ruleset enabled |
| Bot Fight Mode | Enable on zone to reduce scripted free-tier abuse |
